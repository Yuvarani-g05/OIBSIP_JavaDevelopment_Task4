# Online Examination System

## 📌 Project Overview

The Online Examination System is a Java-based application developed to conduct multiple-choice question (MCQ) examinations. It provides a simple interface for users to attend questions and complete an examination within a specified time.

## 🎯 Objective

The main objective of this project is to simplify the examination process using Java programming and provide a user-friendly interface for conducting online tests.

## ✨ Features

* User Login
* Multiple-Choice Questions (MCQs)
* Countdown Timer
* Question Navigation
* Automatic Submission on Time Expiry
* Examination Result Display

1. Download or clone this repository.
2. Open Eclipse IDE.
3. Import the project into Eclipse.
4. Configure the required Java environment.
5. Run the main class of the application.
6. Log in and start the examination.
